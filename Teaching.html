Courses taught

CSC 221

Data Structures

Covers object-oriented programming, algorithm analysis, recursion, and core data structures and abstract data types using Java.

Semesters taught: Spring 2024 · Fall 2024 · Spring 2025 · Spring 2026 · Fall 2026

CSC 355

Compiler Design

Introduces the major stages of compiler construction, from lexical and syntax analysis through intermediate code, optimization, and code generation.

Course project: SLangCC, a compact classroom compiler that exposes the full pipeline from lexing and parsing to IR and x86-64 code generation.

Semesters taught: Fall 2024 · Fall 2025 · Fall 2026

CSC 356

Computer Security

Introduces computing systems security through threat modeling, cryptography, system hardening, secure coding, and practical security principles.

Semester taught: Fall 2025

CSC 312

Software Design

Explores agile software development, modular design, testing, metrics, and teamwork through a semester-long project for an external user.

Semesters taught: Spring 2024 · Spring 2025 · Spring 2026
