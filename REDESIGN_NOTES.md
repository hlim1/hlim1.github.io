# Profile Page Redesign

The landing page (`index.html`) has been rebuilt as a modern, responsive academic profile.

## Added
- Single-page navigation for About, Research, Selected Work, Education, and Contact
- Responsive mobile navigation
- Updated typography and layout
- Accessible skip link, semantic sections, and reduced-motion support
- Lightweight scroll reveal effects without external JS libraries
- New stylesheet: `stylesheets/profile-v2.css`
- New script: `javascripts/profile-v2.js`

## Existing content preserved
The legacy Education, Projects, Experience, Affiliations, Awards, Korean, and Japanese pages remain in the project and still work as before.
